# Security

Grilly+ runs on a thermometer on your home network. It has an admin password for firmware updates,
a password for its own hotspot, and it checks every update it downloads from GitHub.

## Reporting a vulnerability

Please don't open a public issue. Use **Report a vulnerability** on the
[Security tab](https://github.com/bardesss/grilly-plus/security) instead, so it stays private until
there is a fix. Describe what an attacker can do, from where (same WiFi, the grill's hotspot, the
internet), and how to reproduce it.

Only the [latest release](https://github.com/bardesss/grilly-plus/releases/latest) gets fixes.
